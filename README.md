# portfolio-web

Portafolio personal 3D desarrollado con TypeScript, Vite y Sass para presentar proyectos, arquitectura front-end y experiencia en desarrollo de software.

```bash
npm install
npm run dev      # http://localhost:5173
npm run check    # typecheck + lint + formato
```
